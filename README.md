CCompare

Project Description
CCompare is a car comparison web application which could be used to help less experienced shoppers decide on a car that will suit them best.

Project Goals
1.Display car information
2.Allow users (shoppers) to compare cars based on their choices
3.Login and Registration interfaces
4.Make the web application easy to use and understandable for all users

Technologies Used
1.HTML
2.CSS
3.JavaScript
4.PHP (planned for backend technology)
5.MySQL (planned for databases)

Current Progress
Milestone 1 is focused on the initial structure of the web application, the responsive design and the database schema.
